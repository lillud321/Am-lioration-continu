# Quel outil employer pour quel besoin ?

| Situation | Outil conseillé | Résultat |
|---|---|---|
| Comprendre les frontières du processus | SIPOC | Entrées / sorties / parties prenantes |
| Voir les rôles et transferts | Cartographie à couloirs / BPMN | AS-IS / TO-BE |
| Cibler les défauts les plus fréquents | Pareto | Priorités de traitement |
| Explorer les causes | 5 pourquoi / Ishikawa | Hypothèses structurées |
| Vérifier les causes | Extraction BI / échantillonnage | Preuves |
| Chiffrer l'amélioration | Coût-bénéfice / ROI | Choix de solution |
| Tester la nouvelle façon de faire | Pilote / UAT | Critères d'acceptation |
| Pérenniser | Plan de contrôle + Power BI | Monitoring et amélioration continue |
| Historique d'événements structuré et volumineux | Process mining | Variantes, délais, boucles |

## DMAIC, PDCA ou BPM ?
- **PDCA** : cycle léger et itératif (Plan–Do–Check–Act).
- **DMAIC** : diagnostic rigoureux d'un problème existant, avec mesures avant/après.
- **BPM** : discipline plus large de conception, pilotage et gouvernance des processus.
- **BPMN** : langage de représentation, **pas** une méthode d'amélioration à lui seul.
- **BI** : analyse des données pour éclairer décisions et performance; **pas** un synonyme d'automatisation.

Pour débuter : **DMAIC + cartographie AS-IS/TO-BE + quelques KPI fiables**.
